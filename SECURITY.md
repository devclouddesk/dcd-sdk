# Security Policy

We actively support and provide security updates for the following versions:

| Package | Version | Supported |
| :--- | :--- | :--- |
| `@dcd-sdk/storage-client` | `>= 1.0.0` | :white_check_mark: |
| `dcd-storage-client` (Python) | `>= 1.0.0` | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability within any DevCloudDesk repository or SDK, please do **NOT** open a public GitHub issue.

Instead, please send an email to:
📧 **security@devclouddesk.com**

Please include:
1. Detailed description of the vulnerability.
2. Steps or proof-of-concept script to reproduce.
3. Affected package and version.

We commit to acknowledging your report within 48 hours and keeping you updated as we work on a fix.
